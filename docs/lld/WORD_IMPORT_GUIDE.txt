FORMATTING TIPS FOR WORD
================================================================================

HEADERS & STRUCTURE:
1. Select "Executive Summary" line
   - Set Font: Heading 1 (24pt, Bold)
2. Select "SECTION 1: HIGH-LEVEL SYSTEM CONTEXT" lines
   - Set Font: Heading 2 (18pt, Bold)
3. Select other subsections (Key Features, etc.)
   - Set Font: Heading 3 (14pt, Bold)

SPACING:
1. Select all text (Ctrl+A)
2. Paragraph > Line spacing: Single (1.0)
3. For breaks between sections: Add 1 blank line before heading

MARGINS:
1. Page Layout > Margins > Normal (1 inch all sides)
   OR
   Page Layout > Margins > Custom if you prefer different sizes

FONTS:
1. Body text: Calibri or Times New Roman, 11pt
2. Code blocks: Courier New or Consolas, 10pt
3. Headers: Same font as body, bold
